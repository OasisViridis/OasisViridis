## 01 / Building now

Two complementary directions: verifiable delivery, visible work.

### [`TheMasterplan`](https://github.com/OasisViridis/TheMasterplan) · delivery protocol

**Python · GitHub + Jujutsu**

A lightweight protocol for AI-assisted delivery on GitHub and Jujutsu. It keeps context minimal and puts each hand-off in front of a human decision.

`less context` → `verifiable delivery` → `human decision`

### [`Pioneer`](https://github.com/OasisViridis/Pioneer) · agent workbench

**Electron · TypeScript · thesis project**

A modular desktop workbench for agents: a poster wall of local projects, sessions in tabs, panels that dock anywhere. Tool calls and file edits appear in the interface, not in the chat log.

`project wall` → `tabbed sessions` → `dockable workspace` → `observable actions`

## 02 / Along the way

### [`dsh-persona-hazel`](https://github.com/OasisViridis/dsh-persona-hazel) · persona card and recall

**Python · DeepSeek Harness**

A speaking style distilled from public material into a static persona card with anchor-based recall. Ships as a DeepSeek Harness plugin, no vector search.

### [`Supersonic`](https://github.com/OasisViridis/Supersonic) · multi-screen HMI

**React · FastAPI · WebSocket**

A smart-cockpit prototype: one state snapshot, broadcast over WebSocket to every screen. Baseline frozen August 2026; early thesis work.

### [`IdlerDream`](https://github.com/OasisViridis/IdlerDream) · workspace observer

**Windows · local-first · read-only**

A dashboard watching workspaces and running agent processes. Stopped August 2026, unreleased.
